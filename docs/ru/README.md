# EppTools для Node.js — справочное руководство

**Версия 1.0.0**

Это руководство по `@epptools/sdk` — EPP-клиенту для Node.js. Он открывает TLS-сокет к реестру на
порту 700, пишет командные кадры RFC 5730–5734 и читает ответы. Никакого фреймворка в нём нет и
никакого серверного кода тоже: всё, что здесь описано, — клиентская половина протокола.

## Кому адресовано

Вы подключаете биллинг или выдачу доменов к доменному реестру, который говорит на EPP, пишете на
JavaScript или TypeScript и
впервые имеете дело с EPP, но не впервые — с боевым кодом. Примеры с этих страниц вы будете
копировать в программу, которая тратит деньги, поэтому каждый пример — действительно существующая
команда с теми аргументами, которые она действительно принимает, и в каждом ответ читается, а не
только отправляется команда.

Словарь везде — собственный словарь EPP: сессия, приветствие, команда, ответ, код ответа, объект,
расширение, очередь poll. Там, где метод соответствует конкретной команде или RFC, страница называет
их, чтобы это руководство и руководство регистратора самого реестра можно было держать открытыми
рядом.

```bash
npm install @epptools/sdk
```

Требуется Node.js 16 или новее. Зависимостей нет. Типы TypeScript поставляются вместе с пакетом.

## Два соглашения, которые действуют повсюду

**Даты возвращаются собственной строкой реестра** — `2027-04-01T09:15:00Z`, никогда не как `Date`.
Именно реестр решает, на какой календарный день попадёт продление. Переформатирование через местный
часовой пояс — это то, из-за чего клиент в итоге показывает и продлевает по вчерашнему дню.

**Деньги возвращаются точной десятичной строкой** — `'100.00'`, никогда не числом. В двоичной
плавающей точке `0.1 + 0.2` не равно `0.3`, и просуммированный так баланс уплывает. Пользуйтесь
библиотекой десятичной арифметики или целыми числами в младших единицах валюты.

## Поддержка

Вопросы о библиотеке, о кадре, который отклонил реестр, или об ошибке —
**https://github.com/epptools/node-sdk/issues**.

Приложите `svTRID` из ответа и `clTRID`, который отправил ваш клиент: вместе они указывают на
конкретную транзакцию в журналах реестра, и именно это позволяет ответить на обращение без лишнего
круга уточнений. Пришлите и сами кадры, если можете, но сначала вычеркните `<pw>`, `<newPW>` и
`<authInfo>`: это действующие учётные данные, и по той же причине библиотека маскирует их в
собственных журналах.

Вопросы по учётной записи, расчётам и регистрациям адресуйте своему менеджеру в реестре, а не сюда:
этот адрес — про клиентскую библиотеку.
